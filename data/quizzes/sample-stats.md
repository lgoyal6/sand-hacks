# Sample quiz: Intro Statistics (OpenStax-style, written by us)

1. [mcq] A sample of 25 has mean 40 and standard deviation 10. What is the standard error of the mean?
   - a) 0.4
   - b) 2  (answer)
   - c) 10
   - d) 50
   objective: compute standard error from s and n

2. [mcq] If the sample size quadruples and nothing else changes, the width of a 95% confidence interval for the mean:
   - a) doubles
   - b) halves  (answer)
   - c) quarters
   - d) stays the same
   objective: relationship between n and CI width

3. [numeric] A fair die is rolled twice. What is the probability that the sum is 7? Give a fraction.
   answer: 1/6
   objective: enumerate outcomes in a joint sample space

4. [mcq] A study finds a p-value of 0.03 at alpha = 0.05. Which statement is correct?
   - a) There is a 3% chance the null hypothesis is true
   - b) If the null were true, data this extreme would occur about 3% of the time  (answer)
   - c) The effect is large
   - d) The alternative hypothesis is proven
   objective: interpret a p-value

5. [mcq] Which change reduces the probability of a Type II error, holding alpha fixed?
   - a) Decrease sample size
   - b) Increase sample size  (answer)
   - c) Use a two-sided test instead of one-sided
   - d) Decrease the effect size
   objective: power and sample size
