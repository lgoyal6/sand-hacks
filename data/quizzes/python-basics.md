# Intro Programming: Python Basics

1. [mcq] What does this print? x = [1, 2, 3]; y = x; y.append(4); print(len(x))
   - a) 3
   - b) 4  (answer)
   - c) An error
   - d) None
   objective: understand that assignment shares a reference to a mutable list

2. [numeric] What is the value of 17 // 5 + 17 % 5 in Python?
   answer: 5
   objective: evaluate integer division and the modulo operator

3. [mcq] How many times does the body of this loop run? for i in range(2, 10, 3): ...
   - a) 2
   - b) 3  (answer)
   - c) 4
   - d) 8
   objective: trace range with a start, stop and step

4. [mcq] A function has no return statement. What does calling it return?
   - a) 0
   - b) An empty string
   - c) None  (answer)
   - d) It raises an error
   objective: know the default return value of a Python function

5. [mcq] Which data structure gives the fastest average-case membership test for a large collection?
   - a) list
   - b) tuple
   - c) set  (answer)
   - d) string
   objective: compare lookup cost of hash-based and sequential containers

6. [mcq] What does this print? s = "hello"; print(s[1:4])
   - a) hel
   - b) ell  (answer)
   - c) ello
   - d) hell
   objective: slice a string with an exclusive end index
