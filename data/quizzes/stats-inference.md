# Intro Statistics: Inference

1. [mcq] A 95% confidence interval for a mean is (42, 50). What is the sample mean?
   - a) 44
   - b) 46  (answer)
   - c) 48
   - d) It cannot be determined
   objective: a symmetric confidence interval is centered on the point estimate

2. [mcq] A researcher widens a confidence interval from 90% to 99% using the same data. What happens to its width?
   - a) It gets narrower
   - b) It gets wider  (answer)
   - c) It stays the same
   - d) It depends on the sample mean
   objective: higher confidence requires a larger critical value and a wider interval

3. [numeric] A sample of 100 has standard deviation 20. What is the standard error of the mean?
   answer: 2
   objective: compute standard error as s divided by the square root of n

4. [mcq] A test of H0: mu = 10 gives p = 0.20 at alpha = 0.05. What is the correct conclusion?
   - a) Accept that mu equals 10
   - b) Fail to reject H0; the data are not strong evidence against mu = 10  (answer)
   - c) Reject H0
   - d) There is a 20% chance H0 is true
   objective: interpret a non-significant result without accepting the null

5. [multi] Which changes make a hypothesis test more powerful, holding everything else fixed? Select all that apply.
   - a) Larger sample size  (answer)
   - b) Larger true effect size  (answer)
   - c) Smaller alpha
   - d) Less variability in the data  (answer)
   objective: identify the factors that increase statistical power

6. [mcq] A study finds students who sleep more earn higher grades. Which conclusion is justified?
   - a) More sleep causes higher grades
   - b) Sleep and grades are associated in this sample  (answer)
   - c) Higher grades cause more sleep
   - d) There is no relationship
   objective: distinguish association from causation in observational data
